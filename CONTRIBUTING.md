# Contributing to OpenEMC

Contributions are welcome! Please open an issue to discuss larger changes
before starting work on them.

## Contributor License Agreement

OpenEMC is available under open-source licenses (GNU GPL) and under
commercial licenses. To make this possible, all contributors must accept
the [Contributor License Agreement](CLA.md) before their pull request can
be merged.

You do not need to sign anything in advance. When you open your first pull
request, a bot will post a comment asking you to accept the agreement.
To accept it, reply on the pull request with:

    I have read the CLA Document and I hereby sign the CLA

You need to do this only once; it covers all your future contributions.
If the check does not update, comment `recheck`.

## Pull requests

- Run `cargo fmt` on all crates you changed.
- Make sure the CI build passes.
- Describe user-visible changes in [CHANGELOG.md](CHANGELOG.md).
